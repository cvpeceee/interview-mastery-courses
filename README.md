# Interview Mastery Courses

Interactive, textbook-style HTML courses for senior / staff / principal-level software engineering interview preparation.

## Structure

```
.
├── index.html
├── company/                  # Company-specific courses
│   ├── apple_course.html
│   ├── google_course.html
│   ├── meta_course.html
│   ├── amazon_course.html
│   ├── microsoft_course.html
│   ├── nvidia_course.html
│   ├── openai_course.html
│   └── anthropic_course.html
└── systems/                  # Deep technical courses
    ├── systems_ai_infrastructure_course.html
    ├── specialized_systems_roles_course.html
    └── storage_systems_course.html
```

## How to use

1. Open `index.html` in a browser.
2. Work through the modules. Progress is saved in your browser (localStorage).
3. Study the systems courses for technical depth, then the company courses for process and behavioral framing.

All files are self-contained and work offline.
