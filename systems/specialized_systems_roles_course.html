2. Agentic AI & Systems ML

Time: 10–14 hoursRoles: NVIDIA Agentic AI, Meta Systems ML Compilers

Core concepts

  • Agent architectures: planning, tool use, memory, multi-agent coordination
  • Orchestration frameworks and reliability of agent loops
  • Compilers and runtimes for ML systems (graph optimization, scheduling)
  • Integration of agents with existing systems and data
  • Evaluation, safety, and failure modes of agentic systems

Staff-level depth

  • How to design an agent system that is observable, debuggable, and cost-aware
  • Compiler passes that matter for latency and memory in serving or training
  • Trade-offs between fine-tuned agents vs general tool-using agents
  • Production failure modes: infinite loops, tool misuse, context explosion
Interview Practice
Question: Design an agentic system that can perform multi-step tasks across internal tools while staying within latency and cost budgets.
Approach: Clarify task complexity and reliability requirements. Discuss planner, tool interface, memory, and evaluation. Address failure isolation and observability.
Follow-up: How do you prevent or recover from an agent entering a bad loop?

3. GPU Server / LPU / Robotics Platforms

Time: 12–16 hoursRoles: NVIDIA GPU Server, LPU, Halos Core & Robotics

Core concepts

  • Server-level GPU software stack (firmware, drivers, management)
  • Low-power or specialized units (LPU-style) constraints
  • Robotics platform middleware and real-time requirements
  • Hardware abstraction, telemetry, and fleet management
  • Reliability, thermal, and power management

Staff-level depth

  • How software decisions affect server reliability and serviceability
  • Latency and determinism budgets for robotics control paths
  • Co-design with hardware teams on interfaces and failure handling
  • OTA and update safety for server and robotics platforms
Interview Practice
Question: Design the software architecture for a GPU server platform that must support reliable management, telemetry, and updates at fleet scale.
Approach: Separate management plane from data plane. Discuss firmware, drivers, observability, and safe updates. Address failure domains.
