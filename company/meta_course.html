Recommended focused time: 50–70 hours

1. Interview Process

Time: 4–6 hours

Typical stages

  • Recruiter screen
  • Technical phone screen (45 min, often two problems on CoderPad — code is expected to run)
  • Onsite loop: two coding rounds (“Ninja”), system design (“Jedi” for E4/E5+), behavioral
  • Some loops include an AI-assisted coding round
  • Team matching
Speed and working code matter. Meta values practical correctness over pure cleverness.

2. Coding Preparation (Ninja)

Time: 20–25 hours

What is expected

  • Solve 1–2 medium (sometimes medium-hard) problems in ~45 minutes
  • Code that runs and handles edge cases
  • Clear but concise communication

High-frequency topics: graphs (BFS/DFS, shortest paths), trees, strings, hash maps, dynamic programming, two pointers.

Practice method
Do timed sessions. Aim to finish a medium problem cleanly in 15–20 minutes with testing. Practice narrating just enough to show thinking without slowing down.

3. System Design (Jedi)

Time: 14–18 hours

Common prompts

  • Design News Feed / Instagram
  • Design Messenger / WhatsApp
  • Design top-K trending topics
  • Design typeahead / search suggestions
  • Design file storage or web crawler

Meta expects planetary-scale thinking: sharding, caching, real-time updates, failure handling at extreme scale.

Example approach for News Feed
Clarify: ranking vs chronological? Real-time? Scale of users and posts?
Discuss fan-out on write vs fan-out on read, caching layers, ranking service, and how to handle celebrity accounts or spikes.

4. Behavioral

Time: 6–8 hours

Signals Meta looks for

  • Moving fast and delivering results
  • Collaboration and handling conflict
  • Depth on past projects
